# domino iOS

Native SwiftUI client for [domino](https://domino.fyi) — your second brain, saved via iMessage.

## Requirements

- **Xcode 15+** (full Xcode, not Command Line Tools alone)
- **iOS 17+** deployment target
- Apple Developer account (for device, TestFlight, share extension)

## Quick start

```bash
brew install xcodegen   # if needed
cd ios
xcodegen generate
open Domino.xcodeproj
```

1. Team ID is set in `Config/*.xcconfig` (`2CTC2JW55A`). Change if you use a different Apple team.
2. Select an iPhone simulator or device → **⌘R**

## Universal links setup

AASA is served by the Next.js route
`frontend/src/app/.well-known/apple-app-site-association/route.ts`
(app ID `2CTC2JW55A.fyi.domino.app`).

**Critical:** Apple rejects redirects. Apex `domino.fyi` must return **200** for the AASA
URL — not a 307 to `www`. Fix domain redirects in Vercel if needed (see `AppStore/README.md`).

Verify after deploy:

```bash
curl -sI https://domino.fyi/.well-known/apple-app-site-association
curl -sI https://www.domino.fyi/.well-known/apple-app-site-association
# both: HTTP/2 200  and  Content-Type: application/json
```

Entitlements (`Domino.entitlements`):
- `applinks:domino.fyi`
- `applinks:www.domino.fyi`

## Share extension

Bundle ID: `fyi.domino.app.share`

1. Sign in to the main domino app first (session stored in shared Keychain)
2. In Safari, tap **Share** → **save to domino**
3. Extension POSTs the URL/text to `/items`

Both app and extension share:
- App Group: `group.fyi.domino.app`
- Keychain access group: `$(AppIdentifierPrefix)group.fyi.domino.app`

## TestFlight

1. Create an app in [App Store Connect](https://appstoreconnect.apple.com) with bundle ID `fyi.domino.app`
2. Set `DEVELOPMENT_TEAM` in `Config/*.xcconfig`
3. Run:

```bash
cd ios
chmod +x scripts/testflight.sh
./scripts/testflight.sh
```

4. Upload the IPA via **Transporter** or `xcrun altool`
5. Add testers in App Store Connect → TestFlight

## Local backend dev

In `Domino/App/AppConfig.swift`:

```swift
static let apiBaseURL = URL(string: "http://localhost:8000/api/v1")!
```

Simulator: `localhost` works. Physical device: use your Mac's LAN IP.

## API

Direct to `https://domino-414681726671.us-central1.run.app/api/v1` — no CORS issues (native apps aren't browsers).

## Custom fonts

Web uses Getai Grotesk (proprietary OTF, not in repo). iOS uses **Newsreader** as the display/wordmark substitute and **Figtree** for body — matching the web's Google Font stack in `layout.tsx`.

To add proprietary fonts later, drop OTFs into `Domino/Resources/Fonts/` and register in `DominoTypography.swift` + `UIAppFonts`.
